# Binary Tree Visualizer 

## About the Project
Binary Tree Visualizer is a Python-based GUI application that helps users understand binary tree construction and traversal algorithms through visual representation and animation.

## Features
- Build a binary tree from user-provided integer values.
- Visualize tree nodes and their parent-child relationships.
- Animate binary tree construction.
- Demonstrate Inorder Traversal.
- Demonstrate Preorder Traversal.
- Demonstrate Postorder Traversal.
- Highlight nodes during traversal for better understanding.

## Technologies Used
- Python
- Tkinter
- Data Structures and Algorithms
- Recursion
- Queue

## Getting Started

### Prerequisites
- Python 3.x
- Tkinter

### Installation
1. Clone the repository:

   ```bash
   git clone https://github.com/aditivaidya888-cyber/Binary-Tree-Visualizer.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Binary-Tree-Visualizer
   ```

3. Run the application:

   ```bash
   python main.py
   ```

## How to Use
1. Enter the integer values as requested by the application.
2. Build the binary tree.
3. Visualize the tree structure.
4. Select a traversal algorithm to observe its execution.

## Learning Outcomes
- Understanding binary tree data structures.
- Implementing tree traversal algorithms.
- Learning recursion and queue-based tree construction.
- Developing graphical interfaces with Python Tkinter.
